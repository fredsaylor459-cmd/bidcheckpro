# Product Company Marketing App

This project is an interactive product marketing site built from a TanStack Start template and designed for deployment on Netlify. It includes file-based routing, product listing and detail pages, and a modern React + TypeScript setup.

## Key Technologies

- TanStack Start
- React 19
- TanStack Router (file-based routing)
- TypeScript (strict mode)
- Vite 7
- Tailwind CSS 4
- Netlify (deployment and local dev workflow)

## Run Locally

1. Install dependencies:

```bash
npm install
```

2. Start the development server:

```bash
npm run dev
```

3. Open the app at:

```text
http://localhost:3000
```

## Build

Create a production build with:

```bash
npm run build
```
